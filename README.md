# Netflix Data Analysis and Visualization

This project analyzes Netflix movies and TV shows using **Python, Pandas, and Matplotlib**.

The aim of this project is to explore the Netflix dataset, clean the data, extract meaningful insights, and visualize trends using charts and graphs.

##  Objective

The main objectives of this project are:

* Analyze Netflix movies and TV shows.
* Explore content distribution across different genres.
* Study ratings, release years, and countries.
* Visualize trends using graphs.
* Practice data analysis using Pandas and Matplotlib.

##  Dataset

The project uses the Netflix dataset containing information such as:

* `show_id`
* `type`
* `title`
* `director`
* `cast`
* `country`
* `date_added`
* `release_year`
* `rating`
* `duration`
* `listed_in` (Genre)
* `description`

Some insights obtained from the analysis:

* Movies are more common than TV shows on Netflix.
* Drama and International Movies are among the most popular genres.

* TV-MA is one of the most common content rating.









# 🦠 COVID-19 Data Analysis and Visualization

This project analyzes COVID-19 data using **Python, Pandas, and Matplotlib**.

The goal of this project is to explore COVID-19 cases, deaths, recoveries, and active cases and represent the findings through different data visualizations.

## 🎯 Objective

The main objectives of this project are:

* Analyze COVID-19 cases across different countries.
* Compare confirmed cases, deaths, and recovered cases.
* Identify countries with high numbers of confirmed cases.
* Visualize COVID-19 trends using graphs and charts.
* Practice data analysis using Pandas and Matplotlib.

## 📊 Dataset

The dataset contains COVID-19 information for different countries/regions.

Important columns include:

* `Country/Region`
* `Confirmed`
* `Deaths`
* `Recovered`
* `Active`
* `New cases`
* `New deaths`
* `New recovered`
* `WHO Region`

## 📈 Visualizations

The project includes visualizations such as:

* 📊 Top countries by confirmed cases
* 💀 Countries with the highest deaths
* 💚 Countries with the highest recovered cases
* 📈 Comparison of confirmed, deaths, and recovered cases
* 📊 Active cases by country
* 🌍 COVID-19 cases by WHO region
